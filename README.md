# FoodKeeper 🌿

Projet personnel de conception, déploiement et sécurisation de l'infrastructure informatique d'une start-up fictive de 50 collaborateurs.

## Présentation du projet

FoodKeeper est une start-up fictive spécialisée dans le développement de biocapteurs permettant de détecter la détérioration des aliments et de lutter contre le gaspillage alimentaire.
Ce projet consiste à concevoir progressivement son infrastructure informatique, en reproduisant les principales étapes d'un projet professionnel : analyse des besoins, conception du réseau, déploiement des serveurs, sécurisation et validation.

## Objectifs

* Concevoir un réseau d'entreprise réparti sur trois niveaux.
* Segmenter le réseau en VLAN et mettre en place un plan d'adressage IP.
* Installer et administrer un serveur Linux.
* Gérer les utilisateurs, les permissions et le partage de fichiers.
* Développer un site vitrine pour l'entreprise.

## Technologies envisagées

| Domaine | Technologies |
|---|---|
| Réseau | Cisco Packet Tracer, VLAN, routage inter-VLAN |
| Virtualisation | VMware |
| Systèmes | Debian 13, Windows Server (envisagé) |
| Services | SSH, Samba |
| Sécurité | Pare-feu, ACL |
| Automatisation | Bash |
| Développement web | HTML, CSS, JavaScript |
| Versionnement | Git, GitHub |
